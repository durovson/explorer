# Проверка сборки

11 октября 2026 года, Node.js 24.19.0, официальный CLI 0.2.0.

- 86 локальных тестов прошли: арифметика и точные сравнительные надбавки, адреса TON, поиск транзакций, USDT credit trace, конфигурация, настоящая SQLite, конкурентные переходы, выдача, источник цен Fragment и сценарии бота.
- Проверены синтаксис и граф импортов всех 13 cloud JS modules; отсутствуют Node/npm imports, серверные воркеры и медиа.
- Официальный `tgcloud status` распознал проект и оба update handlers; проект еще не привязан к боту и не опубликован.
- Проверен интерфейс @TheOpenMoneyBot до TON-счета без отправки денег. Источники и цена зафиксированы в docs/REFERENCE-BOT.md.
- Живой публичный запрос цен Fragment через production-модуль с локальным fetch успешно вернул TON 0.010382221 за Star и USD-номинал 0.015000, 11 октября 2026, 01:59 МСК. Это снимок проверки доступности источника, не постоянный тариф. Оплата и авторизация не выполнялись.

Тестовый SDK adapter вызывает SQLite и мок HTTP; он не имитирует все внутренние свойства платформы. Облачный запуск, paid purchase, права доступа к реальному Fragment Connection, миграция реальных старых данных и работоспособность с production ключами не подтверждены. До этого проверки нельзя считать live launch завершенным.

Повторить локально: `npm test` и `npm run check` после `npm ci` и подготовки operator config. Автоматические тесты не отправляют деньги и не вызывают реальные provider API. Для cloud теста нужен свой CLI access token; `tgcloud run` использует настоящую облачную базу и Bot API.
